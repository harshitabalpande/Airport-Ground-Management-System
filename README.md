# Airport Ground Management System

## Project Overview
The Airport Ground Management System is a web-based application developed to organize and manage airport ground operations through a centralized interface.

## Key Features
- User registration and login
- Dashboard for airport ground operations
- Flight management
- Gate allocation
- Ground staff management
- Baggage management
- Fuel operations management
- Login history tracking

## Technologies Used
- Python
- Flask
- MySQL
- HTML and CSS
- Git and GitHub

## Dataset
This project includes an AI-generated/sample dataset for demonstration and academic purposes. The dataset is illustrative and should not be treated as verified real-world airport operational data.

## Local Setup
1. Install Python and MySQL.
2. Create the `airport_ground_management` database and configure its tables.
3. Install the dependencies using:

   `pip install -r requirements.txt`

4. Configure the following environment variables in your terminal or local environment:
   - `DB_HOST`
   - `DB_USER`
   - `DB_PASSWORD`
   - `DB_NAME`
   - `DB_PORT`
   - `SECRET_KEY`

5. Run the application:

   `python app.py`

6. Open `http://127.0.0.1:5000` in your browser.

## Disclaimer
This is an academic portfolio project and is not intended for production use at a real airport without further security, reliability, and operational validation.
